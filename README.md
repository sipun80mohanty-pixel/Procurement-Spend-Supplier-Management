# Procurement Spend & Supplier Management Tracker

## Project Overview

This is a sample procurement data analysis project built using Microsoft Excel and SQL Server.

The project contains 155 purchase orders and 15 suppliers and focuses on purchase order tracking, supplier analysis, procurement spend analysis, and reporting.

## Tools Used

- Microsoft Excel
- SQL Server
- SQL Server Management Studio (SSMS)

## Excel Analysis

- Purchase Order data management
- Supplier master data
- Supplier mapping
- Category-wise spend analysis
- Supplier-wise spend analysis
- Month-wise spend analysis
- PO status analysis
- Late delivery identification
- Pivot Tables
- Dashboard and charts
- Data validation
- XLOOKUP / VLOOKUP
- SUMIF / COUNTIF / IF

## SQL Analysis

- SELECT
- WHERE
- INNER JOIN
- GROUP BY
- SUM
- COUNT
- Aggregate functions
- Supplier-wise spend
- Category-wise spend
- Month-wise spend

## Stored Procedures

- GetSpendByCategory
- GetPendingPOsByAge
